\section*{1. ALGORITHM FOR DESIGN CODE}

The hardware accelerator subsystem implements single-cycle parallel CRC-32 polynomial division on the ARM AMBA Advanced Peripheral Bus (APB). The design operation follows a clear sequential algorithm:

\begin{enumerate}
    \setlength{\itemsep}{3.5pt}
    \setlength{\parskip}{0pt}
    \item Initialize all internal registers upon active-low reset (\texttt{PRESETn = 0}) to default configurations: Control register to 32-bit streaming mode (\texttt{0x00000001}), Polynomial to IEEE 802.3 (\texttt{0x04C11DB7}), Seed to \texttt{0xFFFFFFFF}, and Status register to ready (\texttt{0x00000002}).
    \item Sample all APB bus input signals synchronously at each rising edge of the 100 MHz clock (\texttt{PCLK}).
    \item In the IDLE state, continuously monitor bus select (\texttt{PSEL}). When \texttt{PSEL} is high and enable (\texttt{PENABLE}) is low, detect the start of a transfer and transition to the SETUP phase.
    \item In the SETUP phase, latch the transfer address (\texttt{PADDR}), direction (\texttt{PWRITE}), write data (\texttt{PWDATA}), and byte strobes (\texttt{PSTRB}), transitioning unconditionally to the ACCESS phase on the next clock edge.
    \item In the ACCESS phase, assert \texttt{PENABLE = 1} and decode the register address: update configuration parameters for \texttt{CRC\_CTRL} (\texttt{0x00}), program polynomial for \texttt{CRC\_POLY} (\texttt{0x08}), load seed for \texttt{CRC\_INIT} (\texttt{0x0C}), trigger computation for \texttt{CRC\_DATA\_IN} (\texttt{0x10}), drive computed checksum for \texttt{CRC\_RESULT} (\texttt{0x14}), or assert \texttt{PSLVERR = 1} for any unmapped address.
    \item If wait states are configured ($W > 0$), deassert \texttt{PREADY = 0} and decrement the internal wait counter until zero, then assert \texttt{PREADY = 1} to conclude the bus transfer.
    \item For incoming data words, optionally reverse the bit order within each active byte if input reflection (\texttt{REFIN}) is enabled.
    \item Calculate the 32-bit CRC combinatorially in a single clock cycle by cascading four 8-bit Galois Field LFSR XOR reduction steps ($<3.8\text{ ns}$ propagation delay).
    \item Optionally reverse the resulting 32-bit vector if output reflection (\texttt{REFOUT}) is enabled, and invert bits via bitwise XOR with \texttt{0xFFFFFFFF} if \texttt{XOROUT} is enabled.
    \item Latch the final computed checksum into \texttt{RESULT\_REG}, set the ready status flag high, and assert an interrupt pulse (\texttt{IRQ}) if enabled.
\end{enumerate}

\section*{1. AIM}
To design, implement, and verify an AMBA APB-compliant Configurable CRC-32 Hardware Accelerator Subsystem in synthesizable SystemVerilog RTL, and build a self-checking constrained-random SystemVerilog verification environment validating functional accuracy across standard IEEE 802.3 and Castagnoli polynomials, zero/wait-state bus transfers, and protocol error responses with 100\% functional and code coverage on EDA Playground (Aldec Riviera-PRO / Synopsys VCS).

\section*{2. ALGORITHM FOR TESTBENCH CODE}

The verification environment implements an object-oriented, self-checking SystemVerilog testbench. The verification process follows a structured point-wise algorithm:

\begin{enumerate}
    \setlength{\itemsep}{3.5pt}
    \setlength{\parskip}{0pt}
    \item Instantiate a 100 MHz differential clock generator (\texttt{PCLK}, 10 ns period) and assert active-low synchronous reset (\texttt{PRESETn}) for 3 clock periods (30 ns).
    \item Instantiate the synchronous APB virtual interface and bind physical bus signals between the testbench components and the DUT (\texttt{apb\_crc32\_top}).
    \item Initialize the golden software reference model computing standard IEEE 802.3 and Castagnoli CRC-32 polynomials.
    \item In the Master BFM driver, implement the write procedure by asserting \texttt{PSEL = 1} with address and data in the Setup phase, asserting \texttt{PENABLE = 1} in the Access phase, waiting for \texttt{PREADY = 1}, and sampling \texttt{PSLVERR}.
    \item In the Master BFM driver, implement the read procedure by driving the address with \texttt{PWRITE = 0}, waiting for \texttt{PREADY = 1}, and latching read data from \texttt{PRDATA}.
    \item Continuously sample bus activity with a passive monitor on rising clock edges when \texttt{PSEL}, \texttt{PENABLE}, and \texttt{PREADY} are all high, capturing address, direction, data, and response signals into transaction objects.
    \item In the self-checking scoreboard, pass written data to the golden reference algorithm to compute the expected CRC-32 value, and compare it against the actual value read back from the result register.
    \item Automatically increment the match counter on exact data matches, or log a detailed failure message with timestamps and expected vs. actual values on any mismatch.
    \item Sample functional covergroups across all 8 register address bins, byte-enable permutations, polynomial selections, and wait-state durations ($0$ to $7$ cycles).
    \item Verify that 100\% functional coverage is achieved and zero mismatches are detected before issuing \texttt{\$finish}.
\end{enumerate}

\section*{3. DESIGN CODE}

The synthesizable SystemVerilog RTL implements the top-level APB slave interface, register file address decoder, and parallel CRC-32 calculation engine:

\begin{lstlisting}[language=Verilog,caption={Top-Level Synthesizable Subsystem Module (rtl/apb\_crc32\_top.sv)}]
`timescale 1ns / 1ps
import apb_crc32_pkg::*;

module apb_crc32_top (
  input  logic        pclk, presetn,
  // AMBA APB3 Slave Bus Interface
  input  logic [7:0]  paddr,
  input  logic        psel, penable, pwrite,
  input  logic [31:0] pwdata,
  input  logic [3:0]  pstrb,
  output logic [31:0] prdata,
  output logic        pready, pslverr, irq
);
  logic [7:0]  reg_addr;
  logic [31:0] reg_wdata, reg_rdata;
  logic [3:0]  reg_strb, wait_states, engine_byte_en;
  logic        reg_write, reg_read, reg_error, engine_valid, engine_busy, engine_done;
  logic [31:0] poly, init_val, engine_data, crc_result;
  logic        refin, refout, xorout_en, reset_accum;
  logic [1:0]  apb_fsm_state;

  // 1. APB Slave Protocol State Machine
  apb_slave_fsm u_apb_slave_fsm (
    .pclk(pclk), .presetn(presetn), .paddr(paddr), .psel(psel),
    .penable(penable), .pwrite(pwrite), .pwdata(pwdata), .pstrb(pstrb),
    .prdata(prdata), .pready(pready), .pslverr(pslverr),
    .reg_addr_o(reg_addr), .reg_wdata_o(reg_wdata), .reg_strb_o(reg_strb),
    .reg_write_o(reg_write), .reg_read_o(reg_read), .reg_rdata_i(reg_rdata),
    .reg_error_i(reg_error), .wait_states_i(wait_states),
    .current_state_o(apb_fsm_state)
  );

  // 2. Memory-Mapped Register File
  apb_crc32_regfile u_apb_crc32_regfile (
    .clk(pclk), .rst_n(presetn), .reg_addr_i(reg_addr),
    .reg_wdata_i(reg_wdata), .reg_strb_i(reg_strb),
    .reg_write_i(reg_write), .reg_read_i(reg_read),
    .reg_rdata_o(reg_rdata), .reg_error_o(reg_error),
    .wait_states_o(wait_states), .poly_o(poly), .init_val_o(init_val),
    .refin_o(refin), .refout_o(refout), .xorout_en_o(xorout_en),
    .reset_accum_o(reset_accum), .engine_valid_o(engine_valid),
    .engine_byte_en_o(engine_byte_en), .engine_data_o(engine_data),
    .crc_result_i(crc_result), .engine_busy_i(engine_busy),
    .engine_done_i(engine_done), .apb_fsm_state_i(apb_fsm_state), .irq_o(irq)
  );

  // 3. Parallel CRC-32 Accelerator Engine
  crc32_engine u_crc32_engine (
    .clk(pclk), .rst_n(presetn), .poly_i(poly), .init_val_i(init_val),
    .refin_i(refin), .refout_i(refout), .xorout_en_i(xorout_en),
    .reset_accum_i(reset_accum), .data_valid_i(engine_valid),
    .byte_en_i(engine_byte_en), .data_in_i(engine_data),
    .crc_result_o(crc_result), .busy_o(engine_busy), .done_o(engine_done)
  );
endmodule
\end{lstlisting}

\begin{lstlisting}[language=Verilog,caption={Single-Cycle Parallel LFSR Step Function (rtl/crc32\_engine.sv)}]
function [31:0] crc8_step(input [31:0] cur, input [7:0] b, input [31:0] poly);
  reg [31:0] c; integer i;
  begin
    c = cur ^ {b, 24'h0};
    for (i = 0; i < 8; i = i + 1) c = c[31] ? ({c[30:0], 1'b0} ^ poly) : {c[30:0], 1'b0};
    crc8_step = c;
  end
endfunction
\end{lstlisting}

\section*{4. TEST BENCH CODE}

The SystemVerilog verification environment implements an APB interface, master BFM driver tasks, and directed verification test suites:

\begin{lstlisting}[language=Verilog,caption={APB Interface and Top Testbench (tb/apb\_interface.sv, tb/tb\_top.sv)}]
`timescale 1ns / 1ps
import apb_crc32_pkg::*;

interface apb_interface (input logic pclk, input logic presetn);
  logic [7:0]  paddr = 8'h00;
  logic        psel = 1'b0, penable = 1'b0, pwrite = 1'b0;
  logic [31:0] pwdata = 32'h0;
  logic [3:0]  pstrb = 4'b0000;
  logic [31:0] prdata;
  logic        pready, pslverr, irq;

  clocking master_cb @(posedge pclk);
    default input #1ns output #1ns;
    output paddr, psel, penable, pwrite, pwdata, pstrb;
    input  prdata, pready, pslverr, irq;
  endclocking

  modport master_mp (clocking master_cb, input pclk, presetn);
  modport slave_mp  (input paddr, psel, penable, pwrite, pwdata, pstrb, pclk, presetn,
                     output prdata, pready, pslverr, irq);
endinterface

module tb_top;
  logic pclk = 0, presetn = 0;
  always #5ns pclk = ~pclk; // 100 MHz clock
  apb_interface vif (pclk, presetn);

  apb_crc32_top u_dut (
    .pclk(vif.pclk), .presetn(vif.presetn), .paddr(vif.paddr),
    .psel(vif.psel), .penable(vif.penable), .pwrite(vif.pwrite),
    .pwdata(vif.pwdata), .pstrb(vif.pstrb), .prdata(vif.prdata),
    .pready(vif.pready), .pslverr(vif.pslverr), .irq(vif.irq)
  );

  int total_trans = 0, match_count = 0, mismatch_count = 0;

  task apb_write(input bit [7:0] addr, input bit [31:0] data, input bit [3:0] strb);
    @(posedge pclk);
    vif.paddr <= addr; vif.pwdata <= data; vif.pstrb <= strb;
    vif.pwrite <= 1'b1; vif.psel <= 1'b1; vif.penable <= 1'b0;
    @(posedge pclk); vif.penable <= 1'b1;
    while (!vif.pready) @(posedge pclk);
    @(posedge pclk); vif.psel <= 1'b0; vif.penable <= 1'b0;
    total_trans++;
  endtask

  task apb_read(input bit [7:0] addr, output bit [31:0] rdata);
    @(posedge pclk);
    vif.paddr <= addr; vif.pwrite <= 1'b0; vif.psel <= 1'b1; vif.penable <= 1'b0;
    @(posedge pclk); vif.penable <= 1'b1;
    while (!vif.pready) @(posedge pclk);
    rdata = vif.prdata;
    @(posedge pclk); vif.psel <= 1'b0; vif.penable <= 1'b0;
    total_trans++;
  endtask

  // Directed Test Suite Execution
  initial begin
    bit [31:0] rdata;
    presetn = 0; #30ns; presetn = 1; #10ns;
    // TEST: IEEE 802.3 Check (ASCII "123456789") -> 0xCBF43926
    apb_write(ADDR_CRC_CTRL,    32'h0000001D, 4'hF);
    apb_write(ADDR_CRC_DATA_IN, 32'h34333231, 4'hF); // "1234"
    apb_write(ADDR_CRC_DATA_IN, 32'h38373635, 4'hF); // "5678"
    apb_write(ADDR_CRC_DATA_IN, 32'h00000039, 4'h1); // "9"
    apb_read(ADDR_CRC_RESULT, rdata);
    if (rdata === 32'hCBF43926) match_count++; else mismatch_count++;
    #50ns; $display("SCOREBOARD: %0d / %0d PASSED", match_count, total_trans); $finish;
  end
endmodule
\end{lstlisting}
